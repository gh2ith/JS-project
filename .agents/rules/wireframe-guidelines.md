# Bridgeway Wireframe & Design System Guidelines

Whenever creating or modifying wireframes and mockups for this project, always adhere strictly to the following two-tier design standard:

## 1. Low-Fidelity (Lo-Fi) Wireframe Conventions
- **Monochrome Schematic**: Pure black-and-white vector wireframe (`#262626` strokes on `#F5F5F7` canvas, white `#FFFFFF` box fills, `#F4F4F6` secondary fills).
- **Placeholder Language**:
  - Logos: `[X]` box icon with label `LOGO`.
  - Buttons: Boxed pills or rectangles with literal text `[BUTTON]`.
  - Headings: `HEADLINE HERE`, `TITLE HERE`, or `Title Here`.
  - Copy / Body: `Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt ut labore et dolore` and clean horizontal wire stroke lines.
  - Metrics / Stats: Standard wire numbers `00+`, `00%`, `00/0` with `Title Here`.
  - Media & Icons: `[X]` box (rectangle with diagonal crossed lines).
  - Form Fields: Box with `[X]` icon, `TITLE HERE` label, and placeholder text line.
  - Footer: `&copy; 2026 Bridgeway. Built for a better internship experience.`

## 2. High-Fidelity (Hi-Fi) Wireframe & Mockup Artboard Conventions
- **Figma Workspace Presentation**:
  - Header: Figma 4-color icon + "Figma Wireframe • [Page Name]".
  - 12-Column Layout Grid overlay in translucent `#EFF6FF`.
  - Numbered Section Markers in black circular badges (`1`, `2`, `3`, `4`, `5`).
  - Pixel measurement brackets along the left margin (`64px`, `48px`, `24px`, `16px`).
  - Top indicators: `Main Grid` ↓, `Typography` ⟷, `Navigation` →.
  - Right Autolayout Callouts: Arrow lines pointing to key components (`Navigation Header`, `Hero Banner`, `KPI Grid`, `Card Autolayout`, `Primary CTA`, `Security Badge`, etc.).
- **Palette**:
  - Primary Royal Blue: `#2563EB`, `#1D4ED8`.
  - Deep Midnight Navy: `#0F172A`, `#1E3A8A`.
  - Slate Background: `#F8FAFC`, `#F1F5F9`.
  - Surface: `#FFFFFF` with subtle `#E2E8F0` borders and soft shadows.
  - Status Pills: Soft green `#ECFDF5`/`#059669` (Accepted), blue `#EFF6FF`/`#2563EB` (Active), amber `#FFFBEB`/`#D97706` (Pending), red `#FEF2F2`/`#DC2626` (Terminated/Closed).
